## 2025-01-25 - [Fix CSV Injection Vulnerability]
**Vulnerability:** CSV Formula Injection (also known as CSV Injection or Formula Injection). User-controlled fields like names, emails, and addresses were being written directly to CSV exports without sanitization. If a user entered a value starting with `=`, `+`, `-`, or `@` (e.g., `=cmd|' /C calc'!A0`), opening the CSV in Excel could execute arbitrary code or formulas on the admin's machine.
**Learning:** `csv.writer` in Python handles CSV format escaping (quotes, delimiters) but does NOT prevent formula injection. This is a common misconception. Spreadsheet software interprets cells starting with specific characters as formulas regardless of CSV escaping.
**Prevention:** Sanitized all fields in `ExportDataView` by prepending a single quote `'` to values starting with unsafe characters (`=`, `+`, `-`, `@`). This forces spreadsheet software to treat the cell content as a string. Added a reusable `sanitize_for_csv` utility in `store/utils/security.py` and a regression test `store/tests/test_csv_injection.py`.
