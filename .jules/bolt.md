## 2026-01-12 - [N+1 Query Optimization in Product List]
**Learning:** Checking for N+1 queries is critical in DRF serializers with nested fields (`images`, `reviews`) and method fields (`is_in_wishlist`). Optimizing `get_queryset` with `select_related`, `prefetch_related`, and `annotate` is the standard fix. However, optimizing serializer method fields that depend on request user (like wishlist status) requires passing pre-fetched data via `serializer_context` to avoid per-object queries.
**Action:** When auditing DRF views, always check `get_queryset` against `SerializerMethodField` implementations. If a method field hits the DB, pre-fetch that data in the view and pass it via context or use annotations if possible. Also, when testing performance, use `CaptureQueriesContext` to verify query counts before and after changes.
