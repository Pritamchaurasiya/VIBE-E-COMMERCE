## 2024-05-22 - N+1 Queries in Product List
**Learning:** `ProductListView` was suffering from significant N+1 query issues because the serializer accessed related fields (`images`, `reviews`, `wishlist`) that were not prefetched or annotated in the view's queryset. Specifically, `get_images` accessed `obj.images.all()`, and `get_average_rating` and `get_review_count` performed aggregations on `obj.reviews.all()` for each item. Authentication permission defaults (`IsAuthenticated`) also caused regressions in public views when explicit permissions were missing.
**Action:** Always verify `SerializerMethodField` implementations for potential N+1 queries. Use `prefetch_related` for reverse relationships (like images) and `annotate` for aggregations (like ratings/counts) in the view's queryset. Use `serializer.context` to pass bulk-fetched user-specific data (like wishlist IDs) to avoid per-item queries involving `request.user`. Explicitly set `permission_classes` on views if global defaults might change.
