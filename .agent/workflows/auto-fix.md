// turbo-all

1. **Analyze & Fix**: Poore codebase ko scan karke errors, security issues aur bugs ko identify karo aur automatic fix apply karo.
2. **Add Features**: Agar koi naye features ya products add karne hain toh unhe implement karo (jaise `add_more_products.py` run karna).
3. **Verify**: Changes ko verify karne ke liye server ya scripts run karke check karo.
4. **Report**: Jo bhi changes kiye hain unka summary do.
