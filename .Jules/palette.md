## 2026-01-07 - Interactive Feedback for Static Inputs
**Learning:** Users expect interactive feedback even for simple inputs like newsletter subscriptions. Using `Snackbar` provides immediate, delightful confirmation without requiring a page reload or complex backend integration for the initial UI polish.
**Action:** When enhancing static inputs, always pair accessibility improvements (ARIA labels, form wrappers) with visual feedback (toasts, tooltips) to close the interaction loop.
