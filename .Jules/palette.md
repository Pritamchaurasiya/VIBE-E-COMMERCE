## 2026-01-11 - Semantic Grouping for Buttons\n**Learning:** When using a set of buttons to represent a single selection (like radio buttons), using `role='radiogroup'` and `role='radio'` with `aria-checked` is a lightweight accessible alternative to full radio input reimplementation.\n**Action:** Apply this pattern to other selection groups (e.g., color swatches) instead of just using active classes.
